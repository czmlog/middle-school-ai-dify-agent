# Dify 复现步骤

## 一、创建知识库

1. 打开 Dify 控制台。
2. 进入“知识库”。
3. 新建知识库，建议命名为：

```text
中学AI课程官方依据知识库
```

4. 上传以下文件：

```text
knowledge_base/official_sources/*.md
knowledge_base/official_sources/expanded/*.md
```

5. 如希望保留官方原件，也可上传：

```text
knowledge_base/official_sources/raw_pdfs/*.pdf
```

6. 等待索引完成，确认文档状态为可用。

建议检索设置：

- 检索方式：向量检索或混合检索
- Top K：建议 6-8
- 召回内容：允许返回来源片段

## 二、导入学生端应用

1. 进入 Dify 应用页。
2. 选择“导入 DSL”。
3. 上传：

```text
dify_apps/student_app_dsl.yml
```

4. 打开工作流编辑器。
5. 找到“官方依据检索”节点。
6. 将知识库绑定为你刚创建的“中学AI课程官方依据知识库”。
7. 检查模型节点是否使用已配置的 DeepSeek 或其他可用模型。
8. 保存并运行测试。

## 三、导入教师端应用

1. 进入 Dify 应用页。
2. 选择“导入 DSL”。
3. 上传：

```text
dify_apps/teacher_app_dsl.yml
```

4. 打开工作流编辑器。
5. 找到“官方依据检索”节点。
6. 重新绑定你创建的知识库。
7. 检查模型节点是否可运行。
8. 保存并运行测试。

## 四、测试学生端

推荐问题：

```text
我想做校园植物图像分类项目，应该怎样准备数据、划分训练集和测试集？
```

期望输出应包含：

- 学习阶段判断
- 数据准备建议
- 训练集与测试集解释
- 测试记录提醒
- 隐私、偏见和 AI 生成标注提醒
- 下一步任务

更多问题见：[examples/student_demo_questions.md](../examples/student_demo_questions.md)。

## 五、测试教师端

推荐输入：

```text
任务类型：实验单生成
年级：八年级
课程主题：用校园植物图片体验图像分类
学生基础：第一次接触机器学习，对训练集、测试集、评价指标理解较弱
课堂限制：45分钟，4人一组，教师提供30张校园植物图片
已有材料：需要学生完成分类体验、测试记录和反思
```

期望输出应包含：

- 学习目标
- 实验流程
- 学生任务单
- 测试记录表
- 评价量规
- 课堂证据采集方案
- 教学反思或申报素材

更多输入见：[examples/teacher_demo_inputs.md](../examples/teacher_demo_inputs.md)。

## 六、常见问题

### 1. 导入后知识库检索报错

通常是因为 DSL 中原有知识库 ID 不存在于你的 Dify 环境。请打开检索节点，重新选择本地创建的知识库。

### 2. 模型节点报错

请检查 Dify 后台是否已经配置 DeepSeek 或其他可用 Chat Model。

### 3. 输出没有引用课程依据

请确认知识库索引完成，并提高检索 Top K，例如设置为 6-8。
