# 学生端使用说明

应用名称：

```text
AI项目学习导师（学生端）
```

## 适用对象

中学信息科技 / 人工智能课程学生，尤其适合项目学习、实验探究和作品完善阶段。

## 支持的问题类型

- AI 项目选题
- 数据准备
- 训练集与测试集理解
- 模型实验与测试记录
- Python 代码排错思路
- 项目展示与反思
- 隐私、偏见、版权和 AI 生成标注

## 使用边界

学生端不会替学生直接完成作业或项目报告。它的定位是：

```text
诊断学习阶段 → 提供项目支架 → 提醒过程证据 → 给出下一步任务
```

## 推荐提问方式

较好的提问：

```text
我想做校园植物图像分类项目，现在不知道怎样划分训练集和测试集，请给我项目支架。
```

不建议的提问：

```text
帮我直接写完整项目报告。
```
