# 课程指导纲要：中学人工智能项目学习对照索引

## 一、官方文件对应

来源文件：《广东省中小学人工智能课程指导纲要（试行）》，广东省教育厅等八部门通知附件 3。

建议检索页码：

- 第 4-6 页：课程性质、基本理念。
- 第 7-8 页：课程目标、核心素养、学段目标。
- 第 9-10 页：课程结构。
- 第 11-17 页：课程内容与学段要求。
- 第 17-19 页：学业质量评价标准。
- 第 19-23 页：课程实施与评价建议。

## 二、核心素养转化为项目学习目标

1. 人智观念：学生能判断人工智能技术适合解决什么问题，知道人机协同的边界，不把 AI 输出当作无需验证的结论。
2. 技术实现：学生能围绕数据、算法、算力和工具平台，描述一个 AI 系统从问题到结果的基本流程。
3. 智能思维：学生能分析系统运行逻辑，发现数据偏差、模型误判和任务边界，并提出改进方案。
4. 伦理责任：学生能关注隐私保护、数据安全、算法偏见、作品标注和技术向善。

## 三、初中阶段项目学习主线

初中阶段建议突出“理解与应用”，把人工智能学习设计成真实情境中的小项目，而不是只讲概念。

推荐项目链条：

1. 真实问题发现：从校园生活、学科学习、社团活动或社区服务中提出问题。
2. 数据准备：确定数据类型、采集方式、样本数量、标注规则、质量风险。
3. 工具体验：使用可视化平台、智能体、低代码工具或国产大模型完成体验与原型。
4. 模型/系统测试：设计测试样例，记录成功、失败和边界情况。
5. 结果解释：分析为什么会误判，哪些样本影响结果，能否换数据或改规则。
6. 伦理反思：说明是否涉及个人信息、版权、偏见、误导性输出或不当使用。
7. 作品展示：展示问题定义、数据证据、操作过程、测试结果、改进建议。

## 四、课程模块与 Dify 输出映射

人工智能与生活：
适合回答“如何从校园问题提出 AI 项目”“某个生活场景是否适合用 AI”。输出应包含问题情境、用户对象、应用价值和限制。

人工智能技术：
适合回答“图像分类、文本分类、语音识别、生成式 AI、数据标注、训练集测试集”等问题。输出应包含数据、算法/模型、工具、测试指标。

人工智能实践与创新：
适合回答“如何做一个作品”“如何用 Dify/低代码平台搭建智能体”“如何写项目报告”。输出应包含需求分析、功能架构、工作流、测试与迭代。

人工智能与社会：
适合回答“隐私、算法偏见、AI 作品标注、学术诚信、技术向善”。输出应包含风险识别、规避策略、教师审核和学生承诺。

## 五、教师端四类任务的依据调用

实验单生成：
应调用课程目标、初中学段要求、课程实施建议。实验单至少包含学习目标、任务情境、数据准备、操作步骤、记录表、反思问题和评价标准。

学生项目评价：
应调用核心素养、学业质量评价标准和学生素养框架。评价要看项目过程，不只看作品是否“像样”。

课堂问题归纳：
应调用教学建议和学段要求，把学生问题归类为概念理解、工具操作、数据质量、模型测试、伦理规范、表达展示。

教学反思生成：
应调用课程实施与评价建议，围绕素养导向、项目实践、多学科融合、平台支撑、过程性评价进行反思。

## 六、评价证据建议

项目学习评价建议采用过程性评价与终结性评价结合。可采集：

1. 问题定义表：说明项目服务对象、应用场景和预期效果。
2. 数据说明表：说明数据来源、样本数量、标注规则、隐私处理。
3. 测试记录表：记录测试样例、预测结果、错误类型、可能原因。
4. 迭代记录：说明修改了哪些数据、提示词、规则或工具参数。
5. 展示材料：项目海报、演示视频、答辩稿、作品链接。
6. 伦理反思：说明个人信息保护、偏见风险、AI 生成内容标注。
