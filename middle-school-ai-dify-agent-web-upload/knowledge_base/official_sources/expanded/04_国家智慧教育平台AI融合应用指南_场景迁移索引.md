# 国家智慧教育平台与 AI 融合应用指南：场景迁移索引

## 一、官方文件对应

来源文件：《国家中小学智慧教育平台与人工智能融合应用指南（试行）》，广东省教育厅等八部门通知附件 4。

建议检索页码：

- 第 7-20 页：平台简介、人工智能通识教育、区域/校本课程资源。
- 第 23-50 页：AI+课程教学。
- 第 50-71 页：AI+师生发展。
- 第 71-88 页：AI+教研科研。
- 第 89-107 页：AI+教育治理。
- 第 107-132 页：AI+家校社共育。
- 第 133-135 页：人工智能工具索引。

## 二、适合本 Dify 案例的场景

AI+课程教学：
用于生成教学设计、实验单、课堂互动问题、项目任务单、学生作品评价表。教师端工作流中的“教学/评价主产物”和“课堂证据方案”主要对应这一场景。

AI+师生发展：
用于支持学生个性化学习、项目辅导、学习计划和学习反馈。学生端“AI项目学习导师”主要对应这一场景。

AI+教研科研：
用于整理教研资料、生成课例反思、归纳课堂问题、形成创AI案例报告素材。教师端“报告素材整理”对应这一场景。

AI+教育治理：
可迁移到信息科技课程管理、校本 AI 课程资源建设、课堂数据归纳和教学质量改进。

## 三、人机协同模式

建议把每一次 AI 应用设计为“人提出任务、AI 生成初稿、人审校修正、再用 AI 迭代、形成可追溯成果”的闭环。

在 Dify 中可落地为：

1. 开始节点收集教师或学生输入。
2. LLM 节点进行任务诊断。
3. 知识检索节点查找官方依据。
4. LLM 节点生成主产物。
5. LLM 节点生成证据采集或反思材料。
6. 结束节点输出结构化结果。

## 四、报告写作证据

为了让创AI案例更有说服力，建议在报告中展示：

1. 官方文件入库截图：证明知识库不是泛泛资料。
2. 工作流截图：展示任务诊断、依据检索、主产物生成、证据方案等节点。
3. 检索命中截图：展示回答调用了课程指导纲要、学生素养框架、教师素养框架等文件。
4. 输出样例：展示实验单、评价量规、学生项目支架、课堂反思。
5. 应用反馈：收集教师试用意见、学生试用意见、节省备课时间、学生作品质量变化等。

## 五、面向评委的表述

本案例的价值不是“能聊天”，而是把国家和广东省人工智能教育文件转化为可执行的教学工作流。教师在输入主题、年级、学情和材料后，系统能自动完成依据检索、教学设计、评价证据和报告素材整理；学生在输入项目想法后，系统能给出符合人工智能素养框架的项目支架和过程证据要求。
