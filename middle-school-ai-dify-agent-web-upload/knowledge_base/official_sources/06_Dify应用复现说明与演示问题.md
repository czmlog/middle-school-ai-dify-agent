# Dify 应用复现说明与演示问题

## 应用名称

学生端：AI项目学习导师（学生端）  
教师端：AI课程教学设计与评价助手（教师端）

## 技术路线

1. 平台：Dify，本地或云端均可部署。
2. 模型：DeepSeek chat 模型。
3. 知识库：中学 AI 课程官方依据知识库。
4. 学生端形态：Advanced Chat/Chatflow。
5. 教师端形态：Workflow。

## 学生端工作流

输入：学生自然语言问题。  
处理：调用大模型和课程知识库，按固定教学格式输出。  
输出结构：

1. 【问题诊断】
2. 【关键提示】
3. 【可尝试做法】
4. 【小例子】
5. 【下一步任务】

学生端适合回答：

1. 什么是训练集和测试集？
2. 我想做“校园垃圾分类识别”项目，怎么设计数据和评价指标？
3. 为什么我的 Python 代码出现 KeyError？
4. 如何判断 AI 生成的答案是不是可靠？
5. 我的小组项目只有演示，没有测试记录，怎样改进？

## 教师端工作流

教师输入：

1. 任务类型：实验单生成、学生项目评价、课堂问题归纳、教学反思生成。
2. 年级。
3. 主题。
4. 学情。
5. 教学材料或学生作品摘要。

教师端适合生成：

1. 一节人工智能项目课实验单。
2. 学生 AI 项目的评价量规和反馈语。
3. 课堂常见问题归纳与下一节课调整建议。
4. 教学反思和案例报告素材。

## 演示输入样例

学生端：

“什么是训练集和测试集？请用中学生能懂的话解释，并给一个课堂小实验建议。”

教师端：

任务类型：实验单生成  
年级：八年级  
主题：用校园植物图片体验图像分类  
学情：学生会使用浏览器和简单表格，但第一次接触机器学习  
材料：本节课 45 分钟，学生 4 人一组，用教师提供的 30 张植物图片完成训练、测试和反思
