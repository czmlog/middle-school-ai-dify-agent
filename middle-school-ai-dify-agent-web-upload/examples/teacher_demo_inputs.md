# 教师端演示输入

## 示例一：实验单生成

```text
任务类型：实验单生成
年级：八年级
课程主题：用校园植物图片体验图像分类
学生基础：学生会使用浏览器和表格，第一次接触机器学习，对训练集、测试集和评价指标理解较弱。
课堂限制：45分钟，4人一组，教师提供30张校园植物图片。
已有材料：学生需要完成分类体验、测试记录和反思。
```

## 示例二：学生项目评价

```text
任务类型：学生项目评价
年级：八年级
课程主题：校园植物图像分类项目
学生基础：学生已经完成项目展示，但测试记录不够完整。
课堂限制：需要给出适合中学生理解的改进建议。
已有材料：项目有数据来源说明、部分预测记录、准确率统计和反思片段。
```

## 示例三：课堂问题归纳

```text
任务类型：课堂问题归纳
年级：八年级
课程主题：训练集、测试集与分类评价
学生基础：第一次接触机器学习。
课堂限制：需要归纳课堂中出现的共性问题，并给出下一课改进建议。
已有材料：学生普遍混淆训练集和测试集，只记录正确数量，没有记录错误类型。
```

## 示例四：教学反思生成

```text
任务类型：教学反思生成
年级：八年级
课程主题：用校园植物图片体验图像分类
学生基础：多数学生能完成分类体验，但对数据偏见和测试集理解不充分。
课堂限制：需要形成一段用于教研交流的教学反思。
已有材料：教师端生成的实验单、学生测试记录、课堂巡视记录和匿名问卷结果。
```
