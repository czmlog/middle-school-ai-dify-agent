# 信息科技课程标准与人工智能课程衔接索引

## 一、官方文件对应

来源文件：《义务教育信息科技课程标准（2022年版）》。

本索引用于说明中学信息科技教师开展人工智能课程案例时，如何把人工智能教育与信息科技课程的数字素养、计算思维、数据意识、项目实践和社会责任相衔接。

## 二、衔接逻辑

信息科技课程强调学生在数字环境中发现问题、分析问题、解决问题，并关注信息社会责任。人工智能课程在此基础上进一步突出数据、算法、模型、智能系统、人机协同和伦理治理。

在中学课堂中，可以把人工智能项目学习设计为信息科技课程能力的综合应用：

1. 数据意识：采集、整理、标注、分析校园或生活数据。
2. 计算思维：把真实问题拆解为输入、处理、输出和评价。
3. 数字化学习与创新：使用 Dify、国产大模型、可视化机器学习平台或低代码工具制作作品。
4. 信息社会责任：关注隐私保护、数据安全、算法偏见、AI 生成内容标注。

## 三、适合中学信息科技教师的项目主题

1. 校园垃圾分类识别：图像分类、数据标注、错误分析、环保教育。
2. 校园植物识别助手：图像采集、分类模型、知识库问答、自然教育。
3. 智能作业反馈助手：文本分类、错因归纳、学习建议、教师复核。
4. 校园活动问答助手：RAG 检索、校本知识库、信息检索与可信来源。
5. 生成式 AI 提示词实验：同一任务下比较提示词质量、输出可靠性和人工核验。

## 四、Dify 案例产出要求

如果报送“教育智能体”，应突出：

- 智能体角色：学生项目导师、教师教学设计助手。
- 交互逻辑：任务诊断、官方依据检索、项目支架/教学产物生成、证据提醒。
- 知识库：广东省课程纲要、学生素养框架、教师素养框架、智慧教育平台应用指南。
- 应用证据：学生对话记录、项目任务单、评价量规、教师反思。

如果扩展为“智能信息系统”，应突出：

- 数据录入：学生项目主题、年级、学情、材料、课堂反馈。
- 数据分析：问题归类、项目阶段诊断、评价维度统计。
- 可视化：项目进度、评价维度达成情况、常见问题分布。
- 策略辅助：下一课调整建议、学生分层支持建议。

## 五、课堂证据模板

1. 教师输入：年级、主题、课时、学情、已有材料。
2. 系统检索：命中的官方文件、章节或页码。
3. 系统输出：实验单、项目支架、评价量规或反思框架。
4. 教师修改：教师对 AI 初稿的删改、补充和本地化处理。
5. 学生实践：学生数据记录、测试记录、作品链接、反思卡。
6. 效果分析：完成率、作品质量、学生兴趣、教师备课效率。
