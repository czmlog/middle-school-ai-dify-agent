# 教师端使用说明

应用名称：

```text
AI课程教学设计与评价助手（教师端）
```

## 支持任务

- 实验单生成
- 学生项目评价
- 课堂问题归纳
- 教学反思生成
- 申报报告素材整理

## 推荐输入字段

```text
任务类型：
年级：
课程主题：
学生基础：
课堂限制：
已有材料：
```

输入越具体，输出越贴近课堂。

## 输出内容

根据任务类型不同，教师端可能输出：

- 教学目标
- 实验流程
- 学生任务单
- 测试记录表
- 评价量规
- 课堂证据采集方案
- 教学反思素材
- 申报报告素材

## 使用建议

1. AI 输出必须经教师审核后使用。
2. 不要输入学生姓名、人脸、联系方式、家庭情况等敏感信息。
3. 用于评价学生作品时，应结合学生真实作品和课堂表现，不应完全依赖模型判断。
4. 输出内容建议保留“AI生成，经教师审核后使用”的标注。
